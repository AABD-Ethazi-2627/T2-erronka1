## Osagai berrien ardura

- CG29 / #36: Filebeat→Kafka raw — petiteiker; NiFi sarrera Niistalekin koordinatu.

Gida berriek falta zen lana esplizitu egiten dute. Ez dute egiaztatzen azaroaren 6ko epea betetzeko gaitasunik: jatorrizko 82 pertsona-egunei 4,5 gehitzen zaizkie estimazio gordin gisa, eta litekeena da zati bat lehendik beste issueetan inplizituki egotea. Bikoizketa eta benetako ahalegin restantea taldean berrikusi, ez batu berrikuspenik gabe konpromiso gisa.

## Hiztegi laburra

- **Train / validation / test**: ikasteko datuak / aukerak doitzeko datuak / azken ebaluaziorako erreserba. Testa ez da berrerabili behar emaitza hobetu arte.
- **FP / FN**: alarma faltsua / hauteman gabeko hutsegitea. Precisionek alarmen fidagarritasuna eta recallek benetako hutsegiteetatik zenbat aurkitu diren neurtzen dute.
- **Offset / replay**: Kafkan kontsumitutako posizioa / mezuak berriz irakurtzea.
- **Idempotentzia**: gertaera bera berriz prozesatzeak ez du emaitza berria bikoizten.
- **422 / 5xx**: API sarrera baliogabea / zerbitzuko errorea. Lehenengoa berrikusi edo baztertu; bigarrenean retry mugatua eta errore-egoera.
- **Fixture**: probetarako sarrera txiki kontrolatua; ez da makina errealaren ebidentzia.
- **Evidence**: benetako komando edo prozeduraren emaitza gordea, bertsioa eta mugak adierazita.
