## Pausoz pauso

1. OK/AVISO/CRITICA kontratua hartu.
2. Arrisku eta anomalia desberdin erakutsi.
3. Makina bereko alerta iraunkorrak multzokatu, originalak mantenduz.
4. Baieztatu/baztertu/ikuskapena planifikatzeko giza prozedura.

## Adibidea edo eskema

Adibide didaktikoa da, ez inplementazio edo proba gainditu baten froga. Kontratuarekin eta instalatutako bertsioekin egokitu. Ez gehitu dependentzia berririk adibidea dagoelako soilik.

```python
def alert_level(p):
    if not 0 <= p <= 1:
        raise ValueError('score out of range')
    return 'CRITICA' if p >= 0.70 else 'AVISO' if p >= 0.15 else 'OK'
assert [alert_level(x) for x in [0.1499, 0.15, 0.6999, 0.70]] == ['OK','AVISO','AVISO','CRITICA']
```
