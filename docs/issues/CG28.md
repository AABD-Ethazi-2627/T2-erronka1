1. scoring/score_api.py eskeletoa osatu.
2. Pydantic sarrera/irteera CG03rekin.
3. Lifespan bidez modelo fidagarria joblib bidez behin kargatu eta hash/bertsioa egiaztatu. Ez kargatu jatorri ezezaguneko pickle/joblib fitxategirik.
4. GET /health eta POST /predict.
5. Erroreak eta baliabide mugak.
6. CG16/14rekin benetako integrazioa.

## Adibidea edo eskema

Adibide didaktikoa da, ez inplementazio edo proba gainditu baten froga. Kontratuarekin eta instalatutako bertsioekin egokitu. Ez gehitu dependentzia berririk adibidea dagoelako soilik.

```bash
  --data-binary @tests/fixtures/predict_valid.json http://localhost:8000/predict
```
