## Adibidea edo eskema

Adibide didaktikoa da, ez inplementazio edo proba gainditu baten froga. Kontratuarekin eta instalatutako bertsioekin egokitu. Ez gehitu dependentzia berririk adibidea dagoelako soilik.

```python
import math

df["temp_diff"] = df["process_temp_K"] - df["air_temp_K"]  # K diferentzia
df["power_est"] = df["rpm"] * df["torque_Nm"]  # proxy, ez watt
df["power_W"] = df["power_est"] * (2 * math.pi / 60)  # potentzia mekaniko ideala
# machine_failure eta failure_* ez dira X-ren parte.
```
