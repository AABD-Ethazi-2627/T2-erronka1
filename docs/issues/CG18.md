## Pausoz pauso

1. timestamp date eta machine_id keyword.
2. score zenbakizkoa, event_id, model_version eta quality.
3. Mapping eta ingest-pipeline bertsionatu.
4. ID politika aukeratu mota bakoitzeko dokumentua ez gainidazteko.
5. Telemetria eta alerta indizeak eta ILM proposamena.

## Adibidea edo eskema

Adibide didaktikoa da, ez inplementazio edo proba gainditu baten froga. Kontratuarekin eta instalatutako bertsioekin egokitu. Ez gehitu dependentzia berririk adibidea dagoelako soilik.

```json
{"properties":{"timestamp":{"type":"date"},"machine_id":{"type":"keyword"},"event_id":{"type":"keyword"},"score_RF":{"type":"double"},"alert_level":{"type":"keyword"}}}
```
