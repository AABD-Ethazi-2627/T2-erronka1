# CG11 aceptación reproducible local

Entorno uv.lock y Python3.11; 42 pruebas locales al cierre del 19/10/2026. Cuaderno
notebooks/01_EDA_evidence.ipynb validado con nbformat y ejecutado de principio a fin
con nbclient. Incluye EDA, distribución de torque/clases, features, particiones y
consulta DuckDB del histórico real conservado. No carga pickles de terceros.

Reproducción desde checkout limpio:
1. `uv sync --frozen --python 3.11`
2. `uv run --frozen python -m scripts.audit_cg02 --check`
3. `uv run --frozen python -m scripts.build_history`
4. `uv run --frozen python -m scripts.experiment_rf`
5. `uv run --frozen python -m scripts.experiment_anomaly`
6. `uv run --frozen python -m scripts.report_thresholds`
7. `uv run --frozen python -m scripts.seasonal_lab`
8. `uv run --frozen python -m unittest discover -s tests -q`

Los experimentos rechazan sobrescribir outputs existentes: preservar versión y
usar una nueva carpeta para repetir RF. El laboratorio estacional usa reglas
inventadas, no nuevas observaciones etiquetadas independientes. 35.040 filas,
cuatro identidades SIM, un año, 24h de censura al final por máquina y purga entre
particiones; no se entrena aquí ningún modelo ni se afirma precisión temporal.
AI4I sigue siendo la única fuente del entrenamiento de clasificación.

La confirmación del usuario permite clasificación actual y generación de un
escenario temporal. No confirma calidad física del simulador. Para generalizar por
temporadas se necesitarían varias temporadas/años y evaluación fuera de las reglas
usadas para generar datos. Revisión del equipo pendiente; issue no cerrada.
