El [JSON activo](CG10_results.json) y la [figura activa](CG10_diagnostics.png)
usan las predicciones de validación ya guardadas, sin entrenar, recalcular scores
ni consumir el test excluido. La lectura conserva el score igual al umbral;
la matriz de la figura procede de los mismos conteos que el JSON.

`uv run --frozen python -m scripts.report_thresholds` genera JSON y figura.
Requiere `outputs/cg08/validation.csv` y `report.json` existentes: este comando
solo recalcula métricas y escenarios sobre esos scores. No ejecutar un experimento
para satisfacer ese prerrequisito dentro de esta conciliación.
AVISO>=0.15 y CRITICA>=0.70 son política de aula fija. El umbral F2 optimizado
(~0.191) es decisión binaria exploratoria; no cambia el contrato de alertas.
Recall/precision validación 32/41=78,05%; TN1150 FP9 FN9 TP32. Nueve fallos no
avisados y nueve inspecciones falsas: no implica adecuación industrial demostrada.
El intervalo bootstrap condicional y las curvas PR/ROC están en los artefactos;
no corrigen selección de modelo ni reutilización de validación.

Se distinguen average precision (AP) y área trapezoidal PR: aquí se reporta AP,
no se renombra silenciosamente como la otra. La precisión base depende de la
prevalencia (41/1200), y accuracy del dummy oculta todos los fallos.

Coste de error hipotético = FP·coste_inspección + FN·horas_parada·1.200 €/h.
Inspección 25/100/300€ y duración .5/1/4h son sensibilidad, no datos observados.
No se multiplica cada FN por 1.200€ sin una duración explícita. Tampoco se
certifican ahorros: ignoramos efectividad y coste de intervenir, falsas alarmas
repetidas y fallos prevenidos. La parada programada cambia lo que observamos:
una alerta seguida de mantenimiento sin fallo puede ser prevención, no un FP.
Para evaluarlo hacen falta acciones/tiempos/resultado y contrafactual defendible.

El registro original de 27 pruebas locales, incluidos .1499/.15/.6999/.70 y
rechazo NaN/fuera de rango, es evidencia histórica, no una ejecución nueva.
