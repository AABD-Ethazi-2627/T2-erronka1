# CG12 laboratorio aislado

Compose raíz ahora declara Kafka3.7, Filebeat9.5.4, NiFi2.0, ES/Kibana9.5.4 y API.
Proyecto `cnc-guard-lab`, sin container_name, puertos solo loopback, volúmenes
propios y límites de memoria. Kibana es perfil dashboard para reducir consumo.
La imagen NiFi local disponible es iabd-nifi:2.0.0-local; otra máquina debe
proporcionarla o definir NIFI_IMAGE para una imagen compatible validada.
No se presupone NFS ni se guardan credenciales SMB en Compose: CNC_STREAM_DIR
apunta a carpeta ya montada de solo lectura o fixtures locales. No se monta red
ni se cambia firewall. API utiliza bundle propio montado de solo lectura.

Kafka-init prepara exclusivamente el volumen nuevo del laboratorio como UID1000;
sin ello el broker no podía escribir bootstrap.checkpoint. NiFi conserva TLS y
credenciales autogeneradas de su imagen. Elasticsearch sin auth solo en esta red
local y loopback: no apto para exposición compartida. Mononodo/replicas0 no da HA.

Validación de configuración: `docker compose config --services`.
Arranque y aceptación vivos se registrarán por componente. Este documento no
certifica todos running antes de consultar endpoints. No hay restart automático
ni despliegue de producción por push. No ejecutar down -v: conservar evidencias.
