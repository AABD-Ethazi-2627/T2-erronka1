|---|---|---|---|---|

`uv run --frozen python -m scripts.report_type_diagnostics`: diagnóstico por tipo
con denominadores y positivos. No se oculta un mal subgrupo con el agregado.
Tampoco se infiere causalidad, equidad laboral o robustez industrial a partir de
estas categorías sintéticas. El RF puede omitir fallos y el IF apenas identifica
1/41 positivos con su presupuesto de alarmas: IF no sustituye ni reduce RF.

## Aplicabilidad normativa: decisión pendiente, no certificación

El prototipo actual es un ejercicio simulado de apoyo humano, sin control de CNC
ni función de seguridad validada. No se declara alto riesgo, exclusión legal o CE
solo por usar ML. Para una entrega real hay que fijar uso previsto, fabricante,
integrador, usuario profesional, interfaces y consecuencias de un fallo, y comprobar
la versión normativa vigente con asesoramiento competente. El fabricante/integrador
no transfiere su responsabilidad al alumno por llamar a una API; el usuario debe
respetar el uso previsto y conservar intervención/supervisión según corresponda.
