# CG08 experimento controlado

`uv run --frozen python -m scripts.experiment_rf --output outputs/cg08`
10 candidatos: dummy negativo, logística balanceada y RF con/sin física,
con/sin class_weight y profundidad 8/12. Mismos cuatro folds estratificados.
Cada imputador/encoder/escala se ajusta dentro del fold; no SMOTE global.
Selección RF por average precision OOF, ajuste F2 del umbral en validación.
No se ha vuelto a medir el test antiguo. Su pertenencia coincide exactamente
con source_row_indices del reporte v1 de PR29 (verificación local).

CG08_results.json contiene métricas, versiones, parámetros y SHA-256 de fuente
/modelo. outputs/cg08 contiene modelo, manifest completo de folds y scores.
La recarga reproduce probabilidades exactamente. Los resultados de búsqueda
OOF y ajuste de umbral son optimistas y NO son test final independiente.
La importancia RF no demuestra causalidad; se prefiere ablación controlada de
features frente a convertir importancia en efecto industrial.
No se reemplaza el bundle del PR29 ni se entrega aún un modelo al API.
Revisión de otro miembro y reconciliación con CG04/CG28 pendientes.

## Comparación SMOTENC adicional

`uv run --frozen python -m scripts.experiment_smotenc` usa exactamente los mismos
folds guardados; imbalanced-learn0.12.4 queda fijado en uv.lock. Imputación y
SMOTENC se ajustan dentro de cada train-fold. La categoríaH/M/L se conserva como
tal; se sintetizan sensores originales y después se recalculan las features
físicas, evitando potencias interpoladas inconsistentes. Estrategia.2,k3,seed42.
CG08_smotenc.json compara OOF y validación de desarrollo con RF sin sobremuestreo.
No se promueve silenciosamente al API; no se reevalúa el test antiguo. Los puntos
sintéticos no son nuevos fallos observados y necesitan análisis de plausibilidad.

Referencia primaria: https://imbalanced-learn.org/stable/over_sampling.html

interpretación sigue pendiente, no se exige fingir que necesariamente mejora.
