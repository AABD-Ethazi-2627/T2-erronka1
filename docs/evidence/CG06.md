# CG06 histórico local reproducible

`uv sync --frozen --python 3.11` y `uv run --frozen python -m scripts.build_history`.
Bronze conserva bytes con SHA-256; Silver particiona por fecha de emisión UTC,
Gold se calcula con DuckDB. La identidad hash del archivo + ordinal conserva los
estados distintos con igual máquina/hora. Reprocesar un archivo no duplica filas.
Resultados y hashes: CG06_history.json (4 fuentes / 40 filas).

No es captura continua de SMB ni garantiza retención del servidor. Un hash nuevo
con filas repetidas se conserva como nueva emisión; no prueba nueva observación
independiente. Las banderas se conservan para diagnóstico offline y no se pasan al
modelo. Gold agrupa identificadores simulados, no historia física fiable. No hay
imputación de fechas al training. El lock local permite trabajar sin modificar la
tarea CG04 de otro miembro; deberá reconciliarse con su entorno antes del merge.
Revisión de otro miembro pendiente.
