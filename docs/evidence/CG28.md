# CG28 API local probada

`uv run --frozen python -m scripts.package_model` empaqueta solo los artefactos
locales cuyo hash coincide con sus reportes. `uv run --frozen uvicorn
scoring.score_api:app --host 127.0.0.1 --port 18000` sirve el laboratorio.
Manifest propio de confianza: SHA-256 no protege si un atacante reemplaza también
el manifest. No aceptar modelo/manifest subidos por clientes.

Lifespan carga una vez, valida todos los hashes antes de deserializar, compara
sklearn y ejecuta inferencia de prueba. Falta/corrupción -> health503 y predict503.
Pydantic estricto rechaza etiquetas/faltas/valores inválidos con422; límite32KiB
con413. Fallo interno ->500, nunca score0. Inferencia comparte preparación entrenada.

Contrato propuesto prediction0.1.0 se amplía con campos opcionales sensores y
alert_level para conservar telemetría al indexar. Sin eliminar campos previos.
Se mantiene policy=f2/risk_threshold offline en risk_alert y alert_level fijo
OK/AVISO/CRITICA con .15/.70: son dos decisiones distintas y documentadas.
La propuesta requiere revisión del equipo antes de congelar versión pública.

CG28_http.json registra 30 llamadas HTTP reales loopback, identidad conservada,
respuesta completa y latencia p50/p95/max. Es carga secuencial caliente, no prueba
de concurrencia o plazo industrial. Tests cubren modelo ausente/corrupto, cuerpo
grande, contrato, valor inválido y misma instancia cargada entre requests.
El score RF no está calibrado como probabilidad industrial ni forecast24h.

Referencia de implementación: FastAPI lifespan/testing oficial:
https://fastapi.tiangolo.com/advanced/testing-events/
