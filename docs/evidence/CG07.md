# CG07 features y particiones

`scoring/preparation.py` selecciona explícitamente cinco sensores y machine_type.
Excluye todos los resultados, machine_id y cualquier fecha. temp_diff (K),
power_W = rpm·torque·2π/60 (W mecánicos ideales), wear_torque (min·Nm, proxy de
esfuerzo acumulado, no desgaste medido). rpm·torque sin conversión no son W.

Se conserva EXACTAMENTE el split 70/15/15 seed42 estratificado de PR29:
5.600 train / 1.200 validación / 1.200 test ya inspeccionado y excluido.
No se rescata independencia cambiando la seed. El test no vuelve a evaluarse.
La validación también se usó anteriormente: nuevas métricas son desarrollo,
no estimaciones finales independientes. Preprocesamiento dentro del Pipeline/CV.
No se aplicará SMOTE fuera de folds; se compara class_weight.
